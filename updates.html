Update Log

Website improvements and changes to Project Forsaken Bot.

v1.13 · November 19, 2026 · Latest
  • Added language selection in Settings with English, Ukrainian, and Russian translations.
  • Language choice is saved and stays in sync across all five pages.
  • Translated navigation, page content, update log, terms, privacy information, and Settings labels.
  • Changed theme collections into expandable accordion sections to keep Settings compact.
v1.12 · November 19, 2026
  • Added a dedicated Gradients collection with Aurora, Sunset, Ocean, Fire, Candy, and Cosmic palettes.
  • Gradient themes now use real two-color blends across primary buttons, gradient headings, the PF brand mark, ambient accents, and particle colors.
  • Added a custom gradient picker with separate start and end colors, saved across all five pages.
  • Added a Holidays collection with New Year, Christmas, Halloween, Valentine's Day, Easter, and Summer palettes.
  • Gradient and holiday themes work in both dark and light modes and retain the existing single-color themes.
v1.11 · November 19, 2026
  • Reorganized the color picker into separate Essentials, Nature, Metallics, and Vibrant collections, plus a dedicated Custom section.
  • Added five new palettes: Teal, Lime, Cyan, Magenta, and Orange.
  • Expanded the Settings dialog with a scrollable layout so every theme remains easy to browse on smaller screens.
  • All 14 built-in themes and the custom picker continue to sync across all five pages and support dark and light modes.
v1.10 · November 19, 2026
  • Added Gold, Bronze, and Steel built-in color themes.
  • Each metallic palette has coordinated dark and light mode colors.
  • New themes work with the existing custom color picker and save across all five pages.
v1.9 · November 19, 2026
  • Added a Red color theme to the built-in palette selection.
  • Added a custom color picker so you can choose your own accent color.
  • Custom colors are saved and synced across all five website pages, with contrast-aware shades for readability in dark and light modes.
v1.8 · November 19, 2026
  • Added five selectable color palettes: Blue, Purple, Emerald, Rose, and Amber.
  • Color choices update accents, buttons, highlights, glow effects, and particles across every page.
  • Selected color themes are saved and remain active when navigating the website.
v1.7 · November 19, 2026
  • Replaced the settings gear with a corrected centered Material Design icon.
  • Restored the brand mark to plain PF text instead of the custom vector monogram.
v1.6 · November 19, 2026
  • Fixed blank icons by embedding SVG markup directly into each page instead of referencing an external SVG sprite.
  • Improved compatibility when opening the site locally from extracted files.
  • Kept the shared icon styling consistent across all five pages.
v1.5 · November 19, 2026
  • Replaced decorative text characters and emoji-style placeholders with a unified SVG icon set.
  • Added matching SVG icons for navigation settings, page cards, social links, and action buttons.
  • Added dedicated GitHub, Discord, and YouTube brand marks.
v1.4 · November 19, 2026
  • Added the Settings button and settings dialog to every page.
  • Settings now stay consistent while navigating between pages.
  • Restored randomized particle sizes, speeds, and left-right drifting paths.
  • Recorded the latest website refresh and usability improvements.
v1.3
  • Added the Update Log page.
  • Added a custom Update Log icon.
  • Improved website consistency.
  • Synced particle and glow effects.
v1.2
  • Added the Links page.
  • Added Terms of Service and Privacy cards.
  • Improved button hover effects.
v1.1
  • Added the animated background.
  • Added the particle system.
  • Updated the homepage layout.
v1.0
  • Website launched.
  • Public bot invite made available.

Privacy Policy

An overview of privacy considerations when using Project Forsaken Bot.

Information handled by the bot

When you interact with a Discord bot, Discord provides information needed to handle the interaction. Depending on the bot’s enabled features, this can include Discord user, server, and channel identifiers, command input, and server configuration. YouTube notification features may also use public channel and video information.

How information is used

Information should be used only to provide, maintain, and troubleshoot the bot’s features. The exact information stored, how long it is kept, and whether it is shared with any other service depend on the bot’s implementation.

Data retention and requests

This page does not currently specify storage periods or a data-deletion process. Those details should be confirmed against the bot’s actual code and hosting setup before this policy is treated as complete.

Transparency note: the previous version said that no personal data was collected. That statement has been removed because the website files alone do not verify what the bot stores or logs. The policy should be completed after checking the bot’s source code and database/logging setup.
